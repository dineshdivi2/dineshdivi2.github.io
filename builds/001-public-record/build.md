# Public Record

A frontend MVP for an Indian civic community: part public noticeboard, part practical action desk.

## The idea

A shared concern needs somewhere to go. Public Record explores a path from a documented issue to evidence, a specific proposal, community discussion and an appropriate action draft.

## What is built

- Browse, search and filter issues, then read their discussion, proposal and evidence.
- Prepare device-local drafts for policy representations, service grievances and RTI requests.
- Copy or download a draft and follow links to official portals for manual review and submission.
- Explore informal ballots and support actions using illustrative activity.

The interface uses plain HTML, CSS and JavaScript, with browser-local storage for visitor changes. Two presentations explore an editorial layout and a simpler community view.

## Where it stands

This is a frontend prototype with sample activity, not a live shared community. There is no shared backend, identity verification or government submission automation. Votes are informal, and changes stay on the same browser and device.

The next substantial step is shared storage and identity-aware participation, alongside consent and moderation.
